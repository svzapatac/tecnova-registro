# TECNOVA 2026 · Registro presencial

Formulario de registro presencial del I Congreso Internacional de Innovación Tecnológica Aplicada – TECNOVA 2026.

Los registros se guardan en Supabase (tabla `registros`) y un flujo de n8n envía el sticker de identificación al correo de cada persona.

- `index.html`: página del formulario.
- `assets/`: logos, foto de la Facultad Tecnológica y tipografía.
